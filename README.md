# IME9 离线中英输入法

包名：`com.malism.ime9`

离线 Android 输入法：英文 QWERTY、简体中文 26 键拼音与九宫格、中英标点、候选联想。不含表情，不声明网络权限。

## 在模拟器或真机上启用

1. Android Studio 打开本工程并安装到设备。
2. 打开应用 **IME9**，点「打开输入法设置」，启用 **IME9 输入法**。
3. 回到应用点「选择输入法」，或在任意输入框的系统键盘图标中切换到 IME9。
4. 输入法已声明 Direct Boot，重启后、首次解锁前以及锁屏密码/PIN 框可以使用（需事先设为当前输入法）。
5. 验证：
   - 中文 26 键输入 `nihao`，候选应有「你好」
   - 中文九宫格输入 `6426`，候选应有「你好」
   - 点选后出现联想（如「好」「的」）
   - 底栏「中 / EN」切换英文 QWERTY
   - 「符」打开标点面板

## 重新生成词库

```
python scripts/build_dict.py
```

词库写入 `app/src/main/assets/dict/`。
