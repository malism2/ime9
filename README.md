# IME9

**One keyboard. Seven languages. Fully on device.**

IME9 是一款离线 Android 输入法。英文、简体中文、阿拉伯语、西班牙语、日语、德语、俄语放在同一个键盘里，词库随应用安装，输入过程不联网。

Package: `com.malism.ime9`

## Languages

| | Language | How you type |
| --- | --- | --- |
| 中 | 简体中文 | 26 键拼音，或九宫格（`6426` → 你好） |
| EN | English | QWERTY，单词补全与下一词联想 |
| ع | العربية | 阿拉伯字母键盘，界面从右到左 |
| ES | Español | QWERTY + ñ 与重音，`nino` → niño |
| あ | 日本語 | 罗马字，`konnichiwa` 空格上屏 こんにちは |
| DE | Deutsch | QWERTZ，ä ö ü ß，`stras` → straße |
| РУ | Русский | ЙЦУКЕН，长按 е 输入 ё，`прив` → привет |

底栏语言键按 **中 → EN → ع → ES → あ → DE → РУ** 循环。长按该键可以直接跳到某一语言。系统输入法列表里也可以按语言切换。

## What you get

- **拼音与九宫格。** 26 键输入 `nihao`，九宫格输入 `6426`，候选里有「你好」。选中之后继续联想，例如「好」「的」。
- **拉丁字母、西里尔字母和阿拉伯字母的补全。** 边输入边出词，上屏后再给出下一词。重音、变音和 ё 可以通过长按键或折叠匹配找到，例如 `nino` 对应 niño，`stras` 对应 straße。
- **日语罗马字。** 输入过程中显示假名，空格上屏首选词或假名。
- **阿拉伯语从右到左。** 键盘、组字区和候选栏都按 RTL 排列。
- **每种语言自己的标点。** 「符」打开符号面板，数字键盘会识别电话、小数和正负号。
- **锁屏也能用。** 输入法声明了 Direct Boot。事先设为当前输入法后，重启后、首次解锁前，以及锁屏密码 / PIN 框都可以调用。

词库是随应用打包的离线词表，覆盖日常用词和下一词联想。中文词表最大，其余语言是精选常用词。需要扩充时，改 `scripts/build_dict.py` 后重新生成即可。

## Install

1. 用 Android Studio 打开本仓库，安装到手机或模拟器。
2. 打开 **IME9**，点「打开输入法设置」，启用 **IME9 输入法**。
3. 回到应用点「选择输入法」，或在任意输入框的键盘图标里切换到 IME9。

Android 要求用户在系统设置里手动启用第三方输入法，安装完成后需要走完上面两步。

## Rebuild the dictionaries

```
python scripts/build_dict.py
```

生成的文件在 `app/src/main/assets/dict/`。每一行是词条或联想对，用制表符分隔。
